# Registro de decisiones (ADR)

Cada ADR documenta una decisión de arquitectura o de datos: el contexto, qué se decidió, qué alternativas se descartaron y qué consecuencias tiene. Un ADR aceptado no se edita: si la decisión cambia, se escribe uno nuevo que lo reemplaza.
